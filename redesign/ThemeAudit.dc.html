Structure and completeness audit

All twenty-one template files are designed and live as separate files, and the four design-system gaps are closed. The directory lists every file; what remains is Liquid conversion, responsive passes at 768 and 390, and real photography.

Phase 1 — completed

One file per template

The combined file has been split. Announcement bar, header, footer and every token remain byte-identical across the six files, so each maps to one Shopify template and its sections without a redesign step.

Added to the system

Four additions, now in place

Documented in DesignSystem.dc.html and used by the new pages. No new visual style was invented outside the system.

Overlay and modal
Scrim value, drawer width, close affordance, entrance timing. Required by cart drawer, quick view, filters, cookie consent and popups.
Long-form prose
Heading levels below H4, lists, block quotes, tables and measure for policies, articles and about.
Data table and status
Order history rows, fulfilment and payment badges, empty rows. No badge or status style exists today.
Feedback and skeleton
Toast, inline field error, form-level error and success, and a loading skeleton fill. Only field focus is defined.
